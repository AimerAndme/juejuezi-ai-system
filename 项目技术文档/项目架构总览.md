# 项目架构总览

## 1. 项目概述

Yu-AI Agent 是一个基于大语言模型的智能代理系统，提供了完整的 RAG（Retrieval-Augmented Generation）能力、多模态处理、数据库集成和智能流程编排功能。系统采用模块化设计，支持多种智能代理模式和复杂的业务场景。

## 4. 核心功能模块

### 4.1 对话记忆管理

**实现方式**：批次化摘要 + 滑动窗口

**核心特性**：

- 每 10-20 条消息生成一次摘要
- 智能触发机制（消息数量 + Token 阈值）
- 维护最近 6 条摘要
- Redis 滑动窗口保持最多 20 条消息
- 批次清空标记避免不必要的缓存重建

**详细文档**：[对话记忆管理方案.md](对话记忆管理方案.md)

### 4.2 RAG 检索系统

**核心特性**：

- 多源检索（专业知识库、通用知识）
- 检索结果重排
- 缓存优化
- 多模态检索支持

**详细文档**：[RAG 检索缓存使用文档.md](RAG检索缓存使用文档.md)

### 4.3 文档处理系统

**核心特性**：

- 文档分片优化

- 多格式支持

**详细文档**：[文档分片优化技术文档.md](文档分片优化技术文档.md)

### 4.4 流程编排系统

**核心特性**：

- 基于 Graph 的可视化流程编排

**详细文档**：[Graph 流程编排技术文档.md](Graph流程编排技术文档.md)

### 4.5 评估系统

**核心特性**：

- 完整的 RAG 评估指标体系
- 检索质量评估（Precision@K、Recall@K 等）

- 自动化评估流程

**详细文档**：[Rag 评估参数文档.md](Rag评估参数文档.md)

## 6. 系统优势

### 6.1 技术优势

1. **模块化设计**：各组件高度解耦，便于独立开发和测试
2. **可扩展性**：支持插件式架构，易于添加新功能
3. **高性能**：异步处理、缓存优化、线程池管理
4. **可靠性**：完善的错误处理和降级机制
5. **灵活性**：多种代理模式和流程编排能力

### 6.2 功能优势

1. **完整的 RAG 能力**：从检索到生成的全流程优化
2. **多模态支持**：处理文本、图像等多种数据类型
3. **数据库集成**：NL2SQL、直接数据库调用
4. **智能记忆管理**：减少 Token 消耗，提升对话质量
5. **全面的评估体系**：持续监控和优化系统性能

### 6.3 应用优势

1. **多场景适配**：从闲聊到专业领域的全方位支持
2. **低资源消耗**：智能缓存和摘要机制
3. **易于集成**：标准 API 接口和丰富的集成选项
4. **可定制性**：灵活的配置和扩展机制
5. **持续优化**：基于评估结果的迭代改进
