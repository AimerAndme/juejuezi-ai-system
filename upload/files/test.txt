1. 项目背景与目标
1.1 项目背景

XX 铜钼矿位于 XX 省 XX 市，是一座新建的大型有色金属矿山。矿石储量丰富，但品位较低（Cu品位0.4-0.6%，Mo品位0.01-0.02%），矿石类型复杂，主要为黄铜矿、辉钼矿与脉石矿物（石英、长石、云母等）的共生体，嵌布粒度细，可浮性差异大。为实现资源的高效回收，降低选矿成本，特委托我院进行选矿厂的工艺流程设计，并对关键技术环节进行优化研究。

1.2 项目目标

设计一套技术先进、经济合理、环保达标的选矿工艺流程。
确保精矿品位和回收率指标达到设计要求：铜精矿品位 ≥ 20%，回收率 ≥ 85%；钼精矿品位 ≥ 45%，回收率 ≥ 80%。
优化药剂制度，降低选矿药剂成本。
评估并推荐节能高效的选矿设备。
为后续的可行性研究和初步设计提供依据。
2. 矿石性质研究
2.1 矿石类型与结构构造

矿石主要为斑岩型铜钼矿，次为矽卡岩型。矿石结构以他形粒状结构、交代结构为主。构造多为块状构造、浸染状构造。原生矿石中黄铜矿、辉钼矿呈不规则粒状、叶片状嵌布于脉石中，次生硫化铜矿物少见。

2.2 主要矿物组成

金属矿物: 黄铜矿（CuFeS₂）、辉钼矿（MoS₂）、黄铁矿（FeS₂）、磁黄铁矿（Fe₁₋ₓS）、赤铁矿（Fe₂O₃）、方铅矿（PbS）、闪锌矿（ZnS）等。
脉石矿物: 石英（SiO₂）、钾长石（KAlSi₃O₈）、斜长石（NaAlSi₃O₈-CaAl₂Si₂O₈）、黑云母（K(Mg,Fe)₃(AlSi₃O₁₀)(OH)₂）、白云母（KAl₂(AlSi₃O₁₀)(OH)₂）等。
2.3 化学成分分析

元素	含量 (%)	备注
Cu	0.45 - 0.58	主要目标元素
Mo	0.012 - 0.019	伴生目标元素
Fe	15.2 - 18.7	需脱除

2.4 粒度嵌布特征

矿石中有用矿物（黄铜矿、辉钼矿）嵌布粒度较细，主要分布在 40μm - 150μm 范围内。其中，-74μm 粒级（细粒级）占比较重，约为总矿量的 35-40%。这要求磨矿细度必须达到 -200目占比 ≥ 85%，以实现单体解离。

3. 选矿试验研究
3.1 磨矿细度试验

在不同磨矿细度条件下进行浮选闭路试验，结果如下：

磨矿细度 (-200目%)	铜回收率 (%)	钼回收率 (%)	铜精矿品位 (%)	钼精矿品位 (%)
75	78.5	72.1	18.2	42.5
80	82.3	76.8	19.5	43.8
85	85.1	79.9	20.1	44.7
90	86.2	81.1	20.3	45.1
95	86.5	81.5	20.4	45.3
结论: 磨矿细度达到 -200目占比85% 时，铜、钼回收率和精矿品位均达到较优水平。继续提高细度，回收率提升不明显，反而增加磨矿成本。

3.2 浮选药剂制度优化

捕收剂: 对比了 Z-200（异丁基黄药）、BK-301（丁基黄药）、Z-200与BK-301复配（1:1）的效果。结果表明，复配捕收剂在保证回收率的同时，能有效提高精矿品位，降低药剂总用量。
起泡剂: 选用 MIBC（甲基异丁基甲醇），用量控制在 20-30 g/t。
抑制剂: 针对黄铁矿，采用石灰（pH=10-11）和少量淀粉进行抑制。针对脉石，考虑添加水玻璃。
活化剂: 对于氧化程度较高的矿石，可考虑添加少量硫酸铜活化黄铜矿。
3.3 浮选流程试验

经过初步探索，确定采用优先浮选工艺，即先浮选铜，再从铜尾矿中浮选钼。

4. 选矿工艺流程设计
4.1 总体工艺流程

原矿 → 破碎 → 磨矿分级 → 铜浮选（粗选、精选、扫选） → 铜精矿、铜尾矿 → 钼浮选（粗选、精选、扫选） → 钼精矿、尾矿。

4.2 破碎流程

采用三段一闭路破碎流程：

粗碎: 1台C160颚式破碎机。
中碎: 1台HP500圆锥破碎机。
细碎: 1台HP400圆锥破碎机，与振动筛组成闭路。
产品粒度: P80 ≤ 12mm。
4.3 磨矿分级流程

采用一段闭路磨矿：

磨机: 1台 φ4.0m × 6.0m 溢流型球磨机。
分级设备: 1台 水力旋流器组（型号待定）与球磨机闭路。
产品细度: P80 = 74μm (-200目 ≈ 85%)。
4.4 铜浮选流程

设备选型: 采用机械搅拌式浮选机。考虑到矿石性质和处理量，推荐使用 XCF/KYF-50 或更大规格的浮选机。
流程结构:
粗选: 1次粗选。
精选: 3次精选（I精选、II精选、III精选），I精选和II精选泡沫返回前一作业，III精选泡沫为最终铜精矿。
扫选: 2次扫选（I扫选、II扫选），I扫选尾矿返回磨矿分级，II扫选尾矿为铜尾矿。
4.5 钼浮选流程

设备选型: 钼浮选作业量相对较小，可选用 XCF/KYF-16 或 XCF/KYF-24 型浮选机。
流程结构:
粗选: 1次粗选。
精选: 4次精选，逐级返回，最终得到钼精矿。
扫选: 2次扫选，尾矿进入最终尾矿库。
4.6 脱水流程

铜精矿: 浓密 → 过滤 → 干精矿。
钼精矿: 浓密 → 过滤 → 干精矿。
尾矿: 浓密后输送至尾矿库。

7. 环保与节能措施
7.1 环保措施

废水: 选矿废水经沉淀、絮凝处理后全部回用，实现零排放或微排放。
废气: 破碎、筛分、输送等环节设置布袋除尘器；浮选车间加强通风。
噪声: 选用低噪声设备，对高噪声源（如磨机、空压机）采取隔声、消声措施。
固废: 尾矿输送至专用尾矿库堆存，并进行生态修复。
7.2 节能措施

高效设备: 选用能效等级高的破碎、磨矿、浮选、泵类等设备。
变频调速: 在风机、水泵等负荷变化大的设备上应用变频技术。
流程优化: 优化磨矿细度，减少过磨；采用选择性好的药剂，降低药耗。
能量回收: 有条件时，利用尾矿库的高程差进行水力发电。
8. 结论与建议
8.1 结论

本研究报告提出的优先浮选工艺流程，结合优化的磨矿细度（-200目85%）和药剂制度，能够有效回收矿石中的铜和钼，达到设计的回收率和品位指标。主要设备选型合理，技术经济指标预测良好，环保节能措施到位，方案可行。

8.2 建议

扩大试验: 建议进行更大规模的连续性试验，验证流程的稳定性和可靠性。
设备考察: 对推荐的主要设备进行深入的市场考察和性能对比，选择最适合本项目的技术和产品。
自动化: 建议配套建设自动化控制系统（如DCS、PLC），实现生产过程的精准控制和优化。
尾矿库设计: 尽早开展尾矿库的详细勘察和设计工作，确保其安全性和经济性。
安全预评价: 开展安全预评价，识别潜在风险，落实安全措施。
