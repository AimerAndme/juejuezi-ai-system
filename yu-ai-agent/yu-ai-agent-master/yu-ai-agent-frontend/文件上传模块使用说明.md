# 文件上传模块使用说明

## 📦 依赖安装

为了获得更好的 MD5 计算性能，建议安装 `spark-md5` 库：

```bash
cd yu-ai-agent-frontend
npm install spark-md5
```

如果不安装 spark-md5，系统会自动使用 Web Crypto API 的 SHA-256 作为替代方案（前 32 位）。

## 🚀 功能特性

1. **分片上传** - 支持 2MB 分片，适合大文件上传
2. **断点续传** - 刷新页面后可继续未完成的上传
3. **秒传** - 通过 MD5 检测已上传文件，实现秒传
4. **文件类型验证** - 仅支持 `.docx`, `.md`, `.pdf`
5. **上传进度** - 实时显示上传进度、速度和预估时间
6. **错误重试** - 分片上传失败自动重试 3 次

## 📋 使用方法

### 1. 在路由中访问

访问 `http://localhost:5173/file-upload` 即可使用文件上传页面。

### 2. 在其他组件中使用

```vue
<template>
  <FileUploader />
</template>

<script setup>
import FileUploader from '@/components/FileUploader.vue'
</script>
```

### 3. API 说明

文件上传相关 API 已封装在 `src/api/fileUploadApi.js`：

- `initiateUpload(data)` - 初始化上传
- `uploadChunk(formData, onUploadProgress)` - 上传分片
- `getUploadStatus(fileMd5, userId)` - 查询上传状态
- `completeUpload(data)` - 完成上传

## 🔧 配置说明

### 后端配置

在 `application.yml` 中配置：

```yaml
file:
  upload:
    chunk-size: 2097152 # 2MB 每片
    temp-dir: ./upload/temp
    final-dir: ./upload/files
```

### 前端配置

在 `FileUploader.vue` 中修改常量：

```javascript
const CHUNK_SIZE = 2 * 1024 * 1024 // 2MB
const MAX_RETRY = 3 // 最大重试次数
```

## 📝 注意事项

1. 确保后端服务已启动（端口 8123）
2. 确保用户已登录（userId 存储在 localStorage）
3. 上传的文件会保存在后端配置的 `final-dir` 目录
4. 临时分片文件会在合并后自动删除
5. Redis 用于存储上传进度，7 天后自动过期

## 🐛 常见问题

### Q: MD5 计算很慢怎么办？

A: 安装 spark-md5 库可以显著提升计算速度。

### Q: 上传中断后如何继续？

A: 选择相同文件，系统会自动检测并显示"断点续传"按钮。

### Q: 如何修改支持的文件类型？

A: 修改 `FileUploader.vue` 中的 `allowedTypes` 数组和后端 `FileUtils.isAllowedFileType` 方法。

### Q: 如何增加分片大小？

A: 同时修改前端 `CHUNK_SIZE` 常量和后端 `application.yml` 中的 `chunk-size` 配置。

## 📊 上传流程

```
1. 选择文件
   ↓
2. 计算文件 MD5
   ↓
3. 初始化上传（检查秒传/断点续传）
   ↓
4. 上传分片（跳过已上传的分片）
   ↓
5. 完成上传（合并分片）
   ↓
6. 清理临时文件
```
