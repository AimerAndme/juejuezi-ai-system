# 全局布局配置说明

> **最新更新**：已模仿 [java2ai.com](https://java2ai.com/) 的现代简洁设计风格

## 设计风格

本项目采用 java2ai.com 的设计理念：

- ✨ **简洁现代**：白色卡片 + 柔和阴影
- 🎨 **蓝色主调**：专业科技感
- 📐 **宽松布局**：更大的内边距和间距
- 🎯 **卡片设计**：清晰的层次结构
- 📱 **响应式**：完美适配各种设备

## 文件位置

`src/styles/global-layout.css` - 全局布局和样式配置中心

## 快速调整指南

### 1. 调整页面左右边距

在 `:root` 变量中修改以下配置：

```css
--page-padding-horizontal: 8px; /* 默认左右边距 */
--page-padding-horizontal-mobile: 6px; /* 平板设备(<768px) */
--page-padding-horizontal-small: 4px; /* 小屏幕(<480px) */
```

**示例：**

- 想要更宽松的边距？改为 `16px`
- 想要更紧凑的边距？改为 `4px`
- 完全无边距？改为 `0px`

### 2. 调整聊天区域间距

```css
--chat-area-margin-horizontal: 8px; /* 聊天区域左右外边距 */
--chat-area-padding: 16px; /* 聊天区域内边距 */
```

### 3. 调整卡片间距（首页应用卡片）

```css
--card-gap: 24px; /* 卡片之间的间隙 */
--card-padding: 24px; /* 卡片内边距 */
--card-margin: 16px; /* 卡片外边距 */
```

/* 主色调 - 蓝色系 */

## 使用方法

### 方法一：使用 CSS 变量（推荐）

在组件中直接使用定义好的 CSS 变量：

```css
.my-element {
  padding: var(--chat-area-padding);
  margin: 0 var(--page-padding-horizontal);
  border-radius: var(--card-border-radius);
}
```

### 方法二：使用工具类

使用预定义的工具类：

```html
<div class="page-container">
  <div class="page-header">
    <div class="back-button">返回</div>
    <h1 class="title">标题</h1>
  </div>

  <div class="content-wrapper">
    <div class="chat-area">
      <!-- 聊天内容 -->
    </div>
  </div>

  <div class="footer-container">
    <!-- 页脚 -->
  </div>
</div>
```

### 方法三：使用主题类

为不同页面应用不同主题：

```html
<div class="page-container theme-love">
  <!-- 恋爱主题 -->
  <div class="page-container theme-mine">
    <!-- 矿山主题 -->
    <div class="page-container theme-super"><!-- 超级智能体主题 --></div>
  </div>
</div>
```

## 常见调整场景

### 场景 1：整体页面太窄，想要更宽的内容区

```css
:root {
  --page-padding-horizontal: 4px; /* 减小边距 */
  --chat-area-margin-horizontal: 4px;
}
```

### 场景 2：移动端内容太挤，想要更多空间

修改响应式配置中的值（在 `@media` 部分）：

```css
@media (max-width: 768px) {
  :root {
    --chat-area-padding: 16px; /* 增加内边距 */
  }
}
```

### 场景 3：首页卡片太密集

```css
:root {
  --card-gap: 32px; /* 增加卡片间距 */
}
```

### 场景 4：统一调整所有页面的视觉间距

只需修改 `:root` 中的变量值，所有页面会自动应用新的配置。

## 注意事项

1. **优先级**：全局样式的优先级低于组件内 `<style scoped>` 中的样式
2. **覆盖方式**：如果某个页面需要特殊配置，在该页面的 `<style>` 中重新定义变量即可
3. **浏览器兼容性**：CSS 变量在现代浏览器中支持良好，IE 不支持
4. **测试建议**：修改后在不同屏幕尺寸下测试效果（桌面、平板、手机）
