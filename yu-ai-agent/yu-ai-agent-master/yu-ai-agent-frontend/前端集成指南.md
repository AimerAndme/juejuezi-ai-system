## 🎯 核心功能实现

### ✅ 文件分片

- 使用 `Blob.slice()` 实现 2MB 分片
- 每个分片独立上传，支持并发控制

### ✅ MD5 计算

- 优先使用 `spark-md5` 库（性能最佳）
- 降级使用 Web Crypto API（SHA-256 前 32 位）
- 支持大文件增量计算，带进度回调

### ✅ 断点续传

- 利用 Redis 缓存已上传分片索引
- 页面刷新后自动检测未完成上传
- 智能跳过已上传分片

### ✅ 秒传功能

- 上传前检查文件 MD5
- 已存在文件直接返回成功

### ✅ 上传进度

- 实时计算上传百分比
- 显示上传速度（KB/s, MB/s）
- 预估剩余时间

### ✅ 错误重试

- 单个分片失败自动重试（最多 3 次）
- 重试间隔递增（1s, 2s, 3s）

### ✅ 取消上传

- 支持中途取消上传
- 已上传分片保留，支持续传

## 📋 API 接口说明

### 1. 初始化上传

```javascript
POST /api/files/upload/initiate
Request Body:
{
  fileName: "test.pdf",
  totalSize: 1024000,
  fileMd5: "abc123...",
  userId: "user001",
  isPublic: false
}

Response:
{
  code: 200,
  data: {
    needUpload: true,
    fileMd5: "abc123...",
    uploadedChunks: [0, 1, 2],
    totalChunks: 10,
    message: "初始化成功"
  }
}
```

### 2. 上传分片

```javascript
POST /api/files/upload/chunk
Content-Type: multipart/form-data
FormData:
  - file: Blob
  - fileMd5: string
  - chunkIndex: number
  - chunkMd5: string
  - userId: string

Response:
{
  code: 200,
  message: "分片上传成功",
  chunkIndex: 3
}
```

### 3. 查询状态

```javascript
GET /api/files/upload/status/{fileMd5}?userId=xxx

Response:
{
  code: 200,
  data: {
    fileMd5: "abc123...",
    status: 0,  // 0: Uploading, 1: Completed
    uploadedChunks: [0, 1, 2],
    totalChunks: 10,
    fileName: "test.pdf",
    totalSize: 1024000
  }
}
```

### 4. 完成上传

```javascript
POST /api/files/upload/complete
Request Body:
{
  fileMd5: "abc123...",
  userId: "user001"
}

Response:
{
  code: 200,
  message: "文件上传完成",
  filePath: "./upload/files/abc123_test.pdf",
  fileName: "test.pdf"
}
```

### 编程式调用 API

```javascript
import {
  initiateUpload,
  uploadChunk,
  completeUpload,
} from '@/api/fileUploadApi'

// 初始化
const response = await initiateUpload({
  fileName: file.name,
  totalSize: file.size,
  fileMd5: md5,
  userId: 'user001',
  isPublic: false,
})

// 上传分片
const formData = new FormData()
formData.append('file', chunk)
formData.append('fileMd5', md5)
formData.append('chunkIndex', 0)
formData.append('chunkMd5', chunkMd5)
formData.append('userId', 'user001')

await uploadChunk(formData, (progressEvent) => {
  console.log('Progress:', progressEvent.loaded / progressEvent.total)
})

// 完成上传
await completeUpload({
  fileMd5: md5,
  userId: 'user001',
})
```

## 📝 注意事项

1. **用户认证**：确保 localStorage 中有 userId
2. **文件类型**：目前仅支持 .docx, .md, .pdf
3. **文件大小**：理论支持任意大小，建议不超过 2GB
4. **并发控制**：当前为串行上传，可优化为并发上传
5. **存储路径**：确保后端配置的目录有写入权限
